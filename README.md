# ☕ Fresánica – Sitio Web Oficial

Bienvenida al repositorio del sitio web **Fresánica**, un espacio dedicado al amor por el café, las malteadas y los postres artesanales.  
Aquí encontrarás el código fuente, los estilos y las mejoras en desarrollo para mantener nuestra página web siempre fresca y funcional.

---

## 🚀 Estructura del proyecto

- `index.html` → Página principal  
- `productos.html` → Muestra los productos y bebidas  
- `galeria.html` → Galería de imágenes  
- `nosotros.html` → Información sobre Fresánica  
- `contacto.html` → Formulario y redes sociales  
- `pedidos.html` → Página de pedidos y encargos  
- `styles.css` → Hoja de estilos principal  

---

## 🧩 Issues del proyecto

Los *issues* se usan para registrar tareas, mejoras o errores que se deben corregir.

|---|-------------------|------|------------|------------|
| 1 | Mejorar diseño del formulario de contacto | Mejora visual | Media | `frontend`, `form`, `style` |

| 3 | Agregar mensaje de confirmación en el formulario | Funcionalidad | Media | `form`, `frontend` |
| 4 | Crear versión responsive para móviles | Adaptabilidad | Alta | `responsive`, `frontend` |
